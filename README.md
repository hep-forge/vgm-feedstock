[![Anaconda Platforms](https://anaconda.org/hep-forge/vgm/badges/platforms.svg)](https://anaconda.org/hep-forge/vgm)

Feedstock for [vgm](https://github.com/vmc-project/vgm) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Virtual Geometry Model, converting geometry between Geant4 and ROOT

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/vgm](https://anaconda.org/hep-forge/vgm).


## Install

```bash
conda install -c hep-forge -c conda-forge vgm
```
